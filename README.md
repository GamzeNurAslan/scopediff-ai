# ScopeDiff AI

ScopeDiff AI is an AI-powered analysis and decision-support system for comparing different versions of design and requirements documents.

The system identifies added, removed, and semantically changed requirements. It also analyzes changes in numbers, durations, conditions, obligations, negations, and scope.

ScopeDiff AI aims to help analysts and developers quickly understand what changed between document versions. It can also prioritize changes that may be related to a reported defect.

## Planned Features

- Semantic requirement matching
- Added and removed requirement detection
- Business rule change detection
- Risk scoring
- Requirement version history
- Defect-related change analysis
- Change visualization dashboard
- Excel report generation

## Data Privacy

This project will use only synthetic and publicly shareable data.

It will not contain:

- Real customer data
- Internal company documents
- Proprietary APIs
- Confidential business information
